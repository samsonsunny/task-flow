### US-003: Refactor ListDetailView to use ViewModel
Status: in_progress
Depends on: US-002

Description:
Wire the ViewModel into the view. Replace all computed properties, mutation methods, and direct modelContext usage with VM calls.

Acceptance Criteria:
- [ ] View creates VM from environment modelContext (3.1)
- [ ] All computed properties replaced with viewModel. references (3.2)
- [ ] All private mutation methods replaced with viewModel. calls (3.3)
- [ ] .onReceive(refreshTimer) calls viewModel.refreshNow() (3.4)
- [ ] .onChange and .onAppear call viewModel.update(...) (3.5)
- [ ] No @Environment(\.modelContext) usage remains in view (3.6)
- [ ] No direct modelContext mutations remain in view (3.7)
